# I build AI tools that run on your machine.

I'm Mayank — a computer science student exploring local AI, agentic systems, and developer tools.

I enjoy bringing separate technologies together to build useful software: local language models, automation, desktop applications, and systems that give developers more control over their tools.

## Selected projects

### [Local URL-to-AI Tutor](https://github.com/Aokiro112/Local-URL-to-AI-tutor)

Turn video URLs into interactive learning experiences with locally running AI.

Combines Ollama, faster-whisper, yt-dlp, and FFmpeg to generate Roman Hinglish study notes, timestamp-grounded answers, transcripts, and revision quizzes.

### [Aokiro](https://github.com/Aokiro112/Aokiro)

A local-first AI coding architect exploring repository understanding, dependency-aware retrieval, structured code generation, and validation-driven editing.

The goal: help AI agents work with existing codebases rather than treating every project like a blank slate.

### [LocalCoder](https://github.com/Aokiro112/Localcoder-AI-coding-agent)

An Ollama-powered coding agent with local development tools, project-aware context, terminal integration, and approval-based safeguards.

### [Jigglypuff](https://github.com/Aokiro112/Jigglypuff)

An offline-first desktop music player built with React and Electron, combining local music libraries with online search, playlists, and Discord Rich Presence.
